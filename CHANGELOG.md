# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-12-01

### 🎉 Initial Release

#### Games
- ✅ Crash Game (Rocket) - Multiplier-based crash game
- ✅ Aviator Red (Jet) - Premium jet-themed variant with 3D graphics
- ✅ Coin Train - Horizontal train-themed multiplayer game
- ✅ Plinko - Physics-based ball drop game
- ✅ Mines - Grid-based gem mining game
- ✅ Coin Flip - Real-time coin flip betting
- ✅ Cycle Race - Premium multiplayer racing game with 10 customizable cyclists
  - Real-time synchronized races across all players
  - Customizable cyclist names and country flags
  - Admin-configurable odds per cyclist
  - Live betting pool monitoring
  - Pending bet system for mid-race betting
  - Provably fair verification
  - Winners history bar with recent race results
- ✅ Wingo - 30-color prediction game

#### Core Features
- ✅ Real-time multiplayer synchronization via WebSocket
- ✅ Provably fair cryptographic verification system
- ✅ Multi-currency support (INR, USD, EUR, GBP, JPY, CNY)
- ✅ Payment gateway integration (Razorpay, Stripe, PayPal, Paytm)
- ✅ Comprehensive admin panel
- ✅ RTP management system
- ✅ Referral and commission system
- ✅ VIP tier progression
- ✅ Live chat support
- ✅ Transaction management
- ✅ Loan system
- ✅ Analytics dashboard

#### Design & UI
